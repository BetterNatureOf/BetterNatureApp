# Team portraits

Satvik Koya supplied his headshot for the public website using this shared image: https://chatgpt.com/s/m_6b07a9b850808191a58d7af425613e54 . The website copy is converted to JPEG and resized to 800 × 800 for loading performance. No facial or visual retouching was applied here.

Additional founders currently use initials. Add their approved portrait path to `team.members[].photo` in website content. LinkedIn links are optional; an absent URL creates no fabricated profile link.

Public chapter headshots can use `photo_url`, `headshot_url`, `avatar_url`, or `photo` in the already-published chapter officer/roster record. The marketing site does not read private user records.
