# Public website design

The user is browsing opportunities in daylight or at home in the evening; the site follows their device appearance.

Use the existing Inter font, forest green and cream identity, with restrained blossom accents. Neutrals are tinted green. Shared surface, text, border and focus tokens live in website/experience.css. Preserve the identity of the existing photos and program illustrations.

Use crisp rounded controls, quiet separators, and purposeful Liquid Glass on metrics and navigation. The adaptive BN pointer merges into small controls, attracts them toward the pointer and springs them back on exit, stays sharp over graphs and highlights map regions. Native text-entry cursors and accessibility fallbacks remain available. Default to CSS transitions. Anime.js owns only the chapter explorer entrance; the existing Motion layer owns the existing hero. ECharts owns chart updates. Respect reduced motion across all three.

Charts use one metric with one unit per view, a public source label, a persistent text/table alternative, and no invented historical comparisons. Device appearance initializes before styles paint, follows OS changes in System mode, and may be overridden explicitly.
